Sobre APEKEYS

Una tienda digital pensada para que comprar un juego sea tan rápido como empezar a jugarlo.

Qué hacemos

APEKEYS es una tienda en línea dedicada exclusivamente a la venta de claves digitales: videojuegos para PC, PlayStation y Xbox, y licencias de software como sistemas operativos y suscripciones. No vendemos productos físicos, por lo que no hay despachos ni tiempos de espera: esta versión académica simula la compra y registra la orden en el navegador.

Cómo trabajamos

Cada producto del catálogo indica de forma explícita la plataforma en la que se canjea la clave, el precio en pesos chilenos y la disponibilidad real en inventario. Cuando un cliente completa una compra, el stock se descuenta automáticamente, de modo que nadie pueda comprar una unidad que ya no existe.

El sitio distingue tres perfiles de usuario. El cliente navega el catálogo y compra; el vendedor puede consultar el inventario y las órdenes; y el administrador gestiona el mantenedor completo de productos y usuarios.

El equipo de desarrollo

Este proyecto fue desarrollado por estudiantes de analista programador de Duoc UC para la asignatura Desarrollo Fullstack II.

Tecnologías utilizadas

  • HTML5 con etiquetado semántico (header, nav, main, section, article, footer).
  • Bootstrap 5.3.8 y CSS3 en una hoja de estilos externa, con variables, grid, flexbox y diseño responsivo.
  • JavaScript para el catálogo, el carrito, las validaciones de formularios y los mantenedores.
